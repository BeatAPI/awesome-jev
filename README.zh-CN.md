# Awesome Jev Projects

由 [BeatAPI](https://beatapi.io) 维护的 JEV 开源实践精选。

这一版不复制参考站的项目列表，也不重新搜索 Twitter。它直接从 2026-09-20
已经整理好的高信号 JEV X 案例中筛选：一位作者只保留一个案例，并且只有能
反查到公开 GitHub 仓库和固定 commit 证据的项目才进入主目录。

## 浏览

- Gallery：https://beatapi.io/awesome-jev-projects
- 数据：[`data/projects.json`](data/projects.json)
- 投稿：[`CONTRIBUTING.md`](CONTRIBUTING.md)

## 每个项目保留三条线索

1. 发现项目的 X 原帖；
2. 项目的 GitHub 原仓库；
3. 能定位实现的固定 commit 文件或目录。

首版共精选 17 个项目，覆盖 Agent 工作流、开发者工具、搜索与数据、开放模型、
界面与自动化、安全与审查六类实践。

`source-reviewed` 只表示我们核对过固定版本的公开源码，不代表已经运行项目、
复现性能、完成安全审计或获得作者背书。X 浏览量和 GitHub Star 都是采集快照。

BeatAPI 使用统一平台 API Key。你可以先在
https://beatapi.io/dashboard/apikeys 创建 Key；在 JEV 的端点、模型 ID、价格与真实
返回完成核验前，本仓库和 Gallery 都不会宣称 JEV 已在 BeatAPI 上线。
