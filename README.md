# Awesome Jev Projects

A focused, source-backed collection maintained by [BeatAPI](https://beatapi.io).

This edition starts from the existing high-signal JEV cases collected on X on
2026-09-20. We keep one case per author, then include only projects with a
public GitHub repository and inspectable fixed-commit evidence.

## What is different

Each entry keeps three independent links:

1. the original X case that surfaced the project;
2. the project’s public GitHub repository;
3. a fixed-commit file or directory showing the implementation.

The first Twitter-derived edition contains 17 selected projects across Agent
workflows, developer tools, search and data, open models, interfaces and
automation, and safety and review.

## Evidence policy

`source-reviewed` means the linked source was inspected at the recorded commit.
It does not mean BeatAPI ran the project, reproduced a benchmark, audited its
security, or received an endorsement. X views and GitHub stars are historical
snapshots.
